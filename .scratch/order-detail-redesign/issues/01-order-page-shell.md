# 01: หน้าคำสั่งซื้อในระบบใหม่: ส่วนหัว สรุป และการชำระ

**What to build:** หน้า /orders/:id บนพื้นกระดาษ สองคอลัมน์แบบ checkout: หัวเป็นสถานะคำสั่งซื้อภาษาไทย (ฟอนต์ display) ใต้หัวเป็น Order Number แบบ mono, สรุปคำสั่งซื้อพร้อมรูปและ "ยอดสุทธิ", ที่อยู่จัดส่ง และปุ่ม "ชำระ ฿…" แสดงทันทีเมื่อยังจ่ายได้ ข้อความกำลังโหลดและ error ตอนโหลดเป็นภาษาไทย พร้อมลิงก์กลับ "คำสั่งซื้อของฉัน"

**Blocked by:** None (can start immediately)
